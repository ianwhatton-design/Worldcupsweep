⚙ Setup Guide

This sweepstake needs a free JSONBin account so that all entries are saved in the cloud and visible to everyone in real time. Takes about 3 minutes.

1
Go to jsonbin.io and sign up for a free account.
2
Once logged in, click API Keys in the top menu. Copy your Secret Key — it starts with $2a$10$...
3
Click Bins → Create a Bin. Paste this as the initial content and save:

{"deck":[],"entries":[]}
4
Copy the Bin ID shown in the URL (looks like 6641f3abc12345).
5
Open worldcup_sweepstake.html in a text editor. Near the top of the <script> section, replace:

const JSONBIN_BIN_ID = '69fc5f25adc21f119a6708c6';
const JSONBIN_API_KEY = '$2a$10$HOYszGzByLJGSR6fYmDiYukgVF1zMzV0gDx/B0iCYbutdsSEKLnQW';

…with your actual Bin ID and Secret Key.
6
Save the file, commit it to your GitHub repo, and you're live! The first page load will automatically shuffle and initialise the draw.
💡 Want to change the host password? Find const HOST_PASSWORD = 'simply2026'; in the script and change it to whatever you like before deploying.
